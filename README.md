# RetailSalesAnalytics
Business Problem

The company possesses historical sales transaction data but lacks a centralized analytical system to monitor sales performance, customer behavior, product demand, and regional performance. Management requires a data-driven dashboard that enables faster decision-making through interactive visualizations and key performance indicators.

Project Objective

Develop an end-to-end Retail Sales Analytics solution using SQL and Power BI to analyze customer transactions, identify business trends, monitor regional performance, evaluate product sales, and generate actionable insights for strategic decision-making.
